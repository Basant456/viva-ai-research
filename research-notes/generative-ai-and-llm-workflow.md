# Generative AI and LLM Workflow Notes

## Current Understanding

---

# What is Generative AI?

Current understanding:

Generative AI refers to AI systems that create new content based on patterns learned from training data.

Generative AI may create:
- text
- code
- images
- audio
- video

For the VIVA-AI project, the main focus is text generation.

---

# What is an LLM?

Current understanding:

LLMs (Large Language Models) are AI models trained on large amounts of text data.

Examples:
- GPT
- Claude
- Gemini
- Llama

LLMs may:
- understand language
- generate text
- answer questions
- summarize information
- generate quizzes

---

# Difference Between Chatbots and LLMs

One important concept I learned is that chatbots and LLMs are not exactly the same.

Current understanding:

LLM:
- underlying language model
- generates text
- processes prompts

Chatbot:
- interface around the LLM
- manages conversation flow
- remembers conversational context

Example:
ChatGPT is a chatbot interface that uses GPT models underneath.

# Educational AI Workflow Understanding

Current understanding of possible workflow:

Student submits assignment
        ↓
Canvas LMS stores submission
        ↓
Submissions API retrieves submission
        ↓
LLM analyzes submission
        ↓
LLM generates verification MCQs
        ↓
Quiz may later connect back into Canvas LMS
