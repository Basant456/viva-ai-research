# viva-ai-research

Research project focused on AI-supported assessment verification using LLM-generated quizzes and Canvas LMS integration.

## Objective
Develop and evaluate an AI-supported assessment verification framework that generates individualized post-submission quizzes using LLMs.

## Research Areas
- Generative AI in Education
- Authentic Assessment
- Canvas LMS Automation
- LLM-generated Verification Quizzes
- Educational Technology

## Technologies
- Python
- Canvas REST API
- OpenAI API
- Flask/FastAPI
- GitHub
